# Hướng dẫn sử dụng

## Bước 1: Cài extension

1. Tải file extension và giải nén.
2. Mở trình duyệt, vào `chrome://extensions`.
3. Bật **Developer mode** (góc trên bên phải).
4. Bấm **Load unpacked**.
5. Chọn thư mục extension đã giải nén (ví dụ `D:/Binance Signal Predictor`).

Sau khi cài xong, bạn sẽ thấy biểu tượng extension trên thanh công cụ.


## Bước 2: Nhận license key trên Telegram

1. Mở bot Telegram: `@zed_crypto_assistant_bot`.
2. Nhấn **Start** hoặc gửi `/start`.
3. Làm theo menu trong bot (`/menu`) để chọn gói.
4. Bot sẽ gửi cho bạn một **license key**.

Lưu lại key này để kích hoạt extension.


## Bước 3: Kích hoạt extension

1. Bấm vào icon extension để mở giao diện.
2. Dán **license key** bạn nhận từ bot.
3. Nhấn nút kích hoạt/xác nhận.
4. Nếu hợp lệ, extension sẽ báo đã kích hoạt thành công.
